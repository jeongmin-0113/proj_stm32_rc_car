# STM32 RC Car

STM32 Nucleo-F411RE와 FreeRTOS로 만든 2륜 RC카입니다.
스마트폰으로 직접 조종하는 **수동 모드**와, 초음파 센서 3개로 주변을 보며 혼자 길을 찾아가는 **자율주행 모드**를 지원합니다.

## 프로젝트 개요

임베디드 부트캠프에서 진행한 프로젝트로, 모터 제어·센서 입력·무선 통신·RTOS 태스크 설계를 실제 하드웨어 하나에 모아 보는 것이 목표였습니다.
직각으로 왼쪽·오른쪽으로 꺾이는 벽 코스를 **벽에 부딪히지 않고 끝까지 주행**하는 것을 기준으로 개발했습니다.

### 구현 기능

- **모터 제어**: L298N 드라이버로 좌우 DC 모터를 구동합니다. TIM3 PWM 두 채널로 바퀴마다 속도를 따로 줄 수 있어서 전진·후진·제자리 회전과 좌우 속도 보정이 가능합니다.
- **무선 조종**: HC-05 블루투스 모듈과 스마트폰 앱(Bluetooth Electronics)의 D-pad로 차를 조종하고, 버튼 하나로 수동/자율 모드를 바꿉니다.
- **거리 측정**: HC-SR04 초음파 센서 3개(앞·왼쪽·오른쪽)를 EXTI 인터럽트와 DWT 사이클 카운터로 측정합니다. 센서끼리 초음파가 섞이지 않도록 순서대로 하나씩 잽니다.
- **자율주행**: 앞이 막히면 왼쪽·오른쪽 중 더 넓은 쪽으로 회전하고, 앞이 열리면 다시 직진합니다. 직진 중 옆 벽에 가까워지면 바깥쪽 바퀴를 느리게 해서 벽에서 멀어지도록 자세를 보정합니다.
- **방향 표시 / 후진 경고**: 현재 움직이는 방향(전진·좌·우)에 맞춰 LED를 켜고, 후진할 때는 부저가 0.5초 간격으로 울립니다.
- **RTOS 구조**: 블루투스·버튼·PC 시리얼·거리 측정·모터 제어를 각각 FreeRTOS 태스크로 나누고, 입력은 메시지 큐로 모터 태스크에 전달합니다. 여러 태스크가 같이 쓰는 LCD는 뮤텍스로 보호합니다.

### 

- 센서 값이 경계에서 흔들릴 때 상태가 계속 바뀌지 않도록 **히스테리시스**(회전 시작 25 cm, 직진 복귀 45 cm)를 적용했습니다.
- 측정 실패 값(`DIST_INVALID`)을 0이나 큰 값으로 처리했을 때 판단이 어떻게 달라지는지 비교하고, 직전 유효 값을 유지하는 방식으로 정리했습니다.
- 좌우 모터 출력 차이 때문에 한쪽 벽에 붙어 가는 문제를 **좌우 PWM 보정**과 센서 위치 조정으로 줄였습니다.

## 주요 기능

- **수동 모드**: 스마트폰 블루투스 앱(Bluetooth Electronics)의 D-pad로 전진·후진·좌회전·우회전·정지
- **자율주행 모드**: 앞·왼쪽·오른쪽 HC-SR04 3개로 거리를 재서
  - 앞이 막히면 더 넓은 쪽으로 제자리 회전
  - 앞이 다시 열리면 직진으로 복귀
  - 옆 벽에 가까워지면 좌우 바퀴 속도를 다르게 줘서 벽에서 멀어지게 보정
- **입력**: 블루투스(HC-05), PC UART 명령, 보드 버튼
- **LCD 표시**: I2C LCD에 현재 상태 출력
- **방향 LED**: 전진이면 앞 LED, 좌회전이면 왼쪽 LED, 우회전이면 오른쪽 LED가 켜짐 (정지·후진 시 모두 꺼짐). 수동·자율 모드 공통
- **후진 경고 부저**: 후진 중 1 kHz 소리를 0.5초 켜고 0.5초 끄기를 반복

## 핀 배치

| 기능 | 핀 | 설정 |
|---|---|---|
| 왼쪽 모터 PWM | PC6 | TIM3 CH1 |
| 오른쪽 모터 PWM | PC8 | TIM3 CH3 |
| 왼쪽 모터 방향 | PB6, PA7 | GPIO Output |
| 오른쪽 모터 방향 | PA5, PA6 | GPIO Output |
| 앞 센서 TRIG / ECHO | PB2 / PA9 | GPIO Output / EXTI |
| 왼쪽 센서 TRIG / ECHO | PB1 / PA8 | GPIO Output / EXTI |
| 오른쪽 센서 TRIG / ECHO | PC4 / PA10 | GPIO Output / EXTI |
| HC-05 TX / RX | PA12 / PA11 | USART6 RX / TX (9600 bps) |
| PC 시리얼 | PA2 / PA3 | USART2 (ST-Link VCP) |
| LCD SCL / SDA | PB8 / PB9 | I2C1 |
| 버튼 (출발·정지 / 좌 / 우) | PC0 / PC1 / PC2 | GPIO Input |
| LED 앞 / 왼쪽 / 오른쪽 | PB5 (D4) / PB10 (D6) / PB4 (D5) | GPIO Output |
| 부저 | PA0 (A0) | TIM2 CH1 PWM |

PWM은 TIM3 (PSC 99, ARR 999) = **1 kHz**입니다. 좌우 모터는 같은 타이머의 다른 채널이라 duty를 따로 줄 수 있습니다.

부저는 모터와 **다른 타이머(TIM2)**를 씁니다. 부저 음 높이를 바꾸려면 ARR(주기)을 바꿔야 하는데, 모터와 같은 TIM3을 쓰면 모터 PWM 주파수까지 같이 바뀌기 때문입니다. TIM2는 1 MHz로 세고(PSC 99), `ARR = 1,000,000 / 주파수 - 1`로 음 높이를 정합니다.

> LED와 부저 핀은 `.ioc`에 설정하지 않고 `indicator.c`에서 직접 초기화합니다. 나중에 CubeMX에서 이 핀을 설정하면 `indicator_gpio_init()` / `buzzer_timer_init()`은 지워야 합니다.

## 소프트웨어 구조

```
Core/Src/
├── ap/
│   ├── message.c/h               # 태스크 간 메시지 정의
│   └── task/
│       ├── bluetooth/bt_task     # HC-05 수신 → BtQueue
│       ├── button/button_task    # 버튼 입력 → BtnQueue
│       ├── comm/comm_task        # PC UART 명령 → CommQueue
│       ├── distance/dist_task    # HC-SR04 3개 측정 → 전역 front/left/right
│       ├── indicator/indicator   # 방향 LED + 후진 부저 (MotorTask에서 호출)
│       └── motor_control/        # 수동/자율 상태머신, 모터 구동
└── driver/
    ├── dc_motor                  # PWM + 방향 핀 제어, 좌우 속도 보정
    ├── led                       # LED on/off/toggle
    ├── buzzer                    # 주파수 지정 PWM 출력
    ├── HCSR04                    # TRIG 펄스, EXTI 양 에지 + DWT로 echo 시간 측정
    ├── button                    # 디바운스
    └── lcd                       # I2C LCD
```

### FreeRTOS 태스크

| 태스크 | 역할 |
|---|---|
| BtTask | 블루투스 문자 수신 → `BtQueue` |
| ButtonTask | 버튼 → `BtnQueue` |
| CommTask | PC 명령 → `CommQueue` |
| DistTask | 앞 → 왼쪽 → 오른쪽 순서로 측정 (센서 사이 17 ms 간격, 간섭 방지) |
| MotorTask | 큐 3개 + 거리 값을 읽어 상태머신 실행, 매 루프 `indicator_update()`로 LED·부저 갱신 |

LCD는 여러 태스크가 같이 쓰므로 `lcdMutex`로 보호합니다.

### 자율주행 상태머신

```
            출발(F / 버튼)
   STOP ─────────────────▶ STRAIGHT ◀───────────────┐
    ▲                        │                       │
    │ 정지(S / 버튼)          │ 앞 ≤ 25 cm            │ 앞 ≥ 45 cm
    │                        ▼                       │
    └──────────────── LEFT / RIGHT ──────────────────┘
                     (왼쪽 ≥ 오른쪽이면 LEFT)
```

- 들어갈 때(25 cm)와 나올 때(45 cm) 기준을 다르게 둬서(히스테리시스) 경계에서 상태가 떨리지 않게 했습니다.
- 직진 중 옆 벽이 15 cm 안으로 들어오면 `motor_forward_corr()`로 한쪽 바퀴를 빠르게, 다른 쪽을 느리게 해서 벽에서 멀어집니다.
- 센서 값이 무효(`DIST_INVALID`)이면 이전 값을 유지합니다.

## 조작법

### 블루투스 (HC-05, 9600 bps)

| 문자 | 동작 |
|---|---|
| `F` | 전진 (자율 모드에서는 출발) |
| `B` | 후진 |
| `L` | 좌회전 |
| `R` | 우회전 |
| `S` | 정지 |
| `M` | 수동 ↔ 자율 모드 전환 |

전원을 켜면 **자율 모드, 정지 상태**로 시작합니다. 속도는 자율 520 / 수동 1000 (최대 999)입니다.

### PC UART (USART2)

| 명령 | 동작 |
|---|---|
| `RUN` | 전진 |
| `STOP` | 정지 |
| `SPD<값>` | 속도 설정 (예: `SPD700`) |

## 빌드

1. STM32CubeIDE에서 이 폴더를 프로젝트로 엽니다.
2. 빌드하고 Nucleo 보드에 업로드합니다 (`proj_stm32_rc_car Debug.launch`).
3. 핀 설정을 바꾸려면 `proj_stm32_rc_car.ioc`를 CubeMX로 엽니다.

## 문제 해결 기록

- **모터가 느려짐**: 건전지가 닳으면 모터 전압이 떨어집니다. 건전지를 바꾸면 해결됩니다.
- **벽 쪽으로 계속 붙음**: 보정 값 변수를 `uint8_t`로 선언해서 음수가 216이 됐습니다. 부호 있는 타입으로 바꿨습니다.
- **벽을 긁으며 감속됨**: 옆 센서를 앞 센서 근처로 옮기고 정확히 90° 방향을 보게 했더니 나아졌습니다.
